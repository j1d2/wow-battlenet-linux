# Ubuntu

Not tested. Do not treat this page as a working install.

Ubuntu installs packages with `apt`. The package names in the Arch guide do not carry over, and some of them may be missing from Ubuntu's own repositories. No `apt` install line is listed here until someone has run it.

After the matching packages are installed, the Lutris steps in the [README](../README.md#install-dxvk-first) are the ones that were run on Arch.
