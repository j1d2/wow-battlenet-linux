# Pop!_OS

Not tested. Do not treat this page as a working install.

Pop!_OS is Ubuntu-based and installs packages with `apt`. The package names in the Arch guide do not carry over. No `apt` install line is listed here until someone has run it.

After the matching packages are installed, the Lutris steps in the [README](../README.md#install-dxvk-first) are the ones that were run on Arch.
