# Contributing

Contributions are under the [Apache License 2.0](LICENSE). Sending a pull request means you agree your change is licensed that way. See section 5 of the license.

The guide is for anyone installing Battle.net and World of Warcraft on Linux. Keep it general. A step that only works on one person's machine does not belong here.

## What to send

- A correction to a step you tried, with the distro and the Lutris version.
- Package names for a distro that is not Arch, in a clearly labeled section.
- A dated note when Blizzard changes how WoW Forever is installed.

## What to leave out

Do not include any of the following, in the guide, an issue, a pull request, or a log paste:

- Email addresses, Battle.net or WoW account names, character names
- IP addresses, hostnames, serial numbers, or home-network details
- A full Battle.net or Wine log. Quote the error line and the version.
- Blizzard's art, logos, screenshots, client files, or paragraphs copied from their site or games. Use the product name. Do not reproduce their material.

GitHub publishes issues and pull requests. A private detail pasted once is hard to take back.

## How

1. Open an issue for anything that is not a small typo, or go straight to a pull request for a typo.
2. Branch from `main`. Do not push to `main`. Branch protection rejects that.
3. Use a [conventional commit](https://www.conventionalcommits.org/) message: `docs:`, `fix:`, or `chore:`.
4. Fill in the pull request template. Add your handle to [CONTRIBUTORS.md](CONTRIBUTORS.md) if this is your first merged change.
5. A maintainer merges. One review is not required, so a single maintainer can land a change after reading it.

## Conduct

[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) applies to issues, pull requests, and commit messages.
