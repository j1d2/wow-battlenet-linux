# Security

This repository is a guide. It does not ship a program, and it does not accept credentials.

## Do not open a public issue for

- A leaked email, account name, log, or other personal detail already committed or pasted
- Anything that would tell a stranger how to reach a specific person

## How to report

For a personal detail that should be removed, or for a problem in this repository, contact [@j1d2](https://github.com/j1d2) on GitHub. Do not put the detail in a public issue.

A broken install step is not a security report. Use an issue template for that.
