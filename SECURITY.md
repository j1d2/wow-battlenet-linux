# Security

This repository is a guide. It does not ship a program, and it does not accept credentials.

## Report it privately

Use GitHub's **private vulnerability reporting**: open the repo's **Security** tab and choose **Report a vulnerability**. Only the maintainer sees it. Use it for:

- A leaked email, account name, log, or other personal detail already committed or pasted
- A step in the guide that would put someone's account or computer at risk
- Anything that would tell a stranger how to reach a specific person

Do not put the detail in a public issue. We aim to reply within 14 days.

A broken install step is not a security report. Use an issue template for that.

See [`security/README.md`](security/README.md): the scans that run on every commit and pull request, and the repository settings.
